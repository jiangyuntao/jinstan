核心能力

一套专为内容增长打磨的基础设施

不塞进臃肿的无关功能，把每个关键环节做到简单、可靠，并且为未来留出边界。

自由内容模型

Article、Page、Product 共用一套 Content API。定义字段，而不是为每一种内容重写基础设施。

SEO 原生内建

从 slug、canonical、Open Graph 到 sitemap、redirect 与 hreflang，所有基础 SEO 能力都在 Core 中。

主题与模板分离

Theme 决定视觉，Layout 决定骨架，Template 呈现内容。每一层都有明确职责，定制不污染核心。

Plugin 扩展边界

通过稳定的公开 API 注册组件、字段、事件、路由与迁移。扩展能力无需修改 Core。

多语言基座

内容翻译、localized slug 与 SEO 字段从数据模型开始考虑；单语言站点也保持清爽。

为 SEO niche 网站而生

轻量核心、明确边界、结构化内容和稳健的升级路径，让你将精力留给真正有效的内容与增长。
