# Changelog

All notable changes are recorded here. This project follows Semantic Versioning after 1.0.0.

## 1.0.0 - 2026-10-04

- Added browser-based installation with SQLite, MySQL/MariaDB and PostgreSQL support.
- Added unified Content Type, Field, Relation and Taxonomy foundations.
- Added server-rendered Admin CRUD, media, navigation, users, roles and settings.
- Added Theme, Layout, Template, Component and Plugin extension systems.
- Added multilingual content foundations and SEO metadata, sitemap, redirect and schema extension APIs.
- Added backups, database maintenance, Core update rollback services and release verification.
- Removed all pre-1.0 compatibility aliases and legacy Admin route redirects.
- Updated dependency and release security checks for the 1.0 line.
